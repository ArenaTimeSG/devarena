# DevArena

Sistema de gerenciamento de agendamentos e pagamentos para arenas esportivas.

## Tecnologias

- React + TypeScript
- Vite
- Supabase
- Tailwind CSS
- Mercado Pago

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Backend

O backend está localizado na pasta `backend/`. Para mais informações, consulte o README na pasta do backend.
